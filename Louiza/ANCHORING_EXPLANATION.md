## Anchoring Process: How Much Real Data & How It's Done

### How Much Real Data is Used?

**ALL available real data is used (100%):**
- Currently: **500 interactions** from `data/real_intent_data.csv`
- **No sampling or subsetting** - uses every single interaction
- All data is used to compute target metrics

### How Anchoring Works

**Step 1: Load Real Data**
```
• Load ALL 500 interactions from data/real_intent_data.csv
• No filtering or sampling
```

**Step 2: Compute Target Metrics from Real Data**
From ALL real data, compute:
- Product-level intent distribution (mean, std per product)
- Segment-level patterns (mean intent per segment)  
- Category-level patterns (mean intent per category)
- Switching rates (how often users switch products)
- Daily trends (temporal patterns over time)
- Habit strength (repeat purchase rates)

**Step 3: Run Phase 3 Simulation (Baseline)**
```
• Generate simulated data using default parameters
• Compute same metrics from simulated data
• Compare: simulated_metrics vs target_metrics
```

**Step 4: Parameter Calibration (25 iterations)**

For each iteration:
1. **Run simulation** with current parameters
2. **Compute simulated metrics** (same structure as target)
3. **Calculate loss:** Sum of squared differences between simulated and target metrics
4. **Adjust parameters** based on differences:
   - If intent too low → increase `agent_state_init_scale`
   - If switching rate wrong → adjust `switching_rate_multiplier`
   - If trend wrong → adjust `transition_momentum`
   - If segment errors → adjust `segment_bias_adjustments`
   - If habit wrong → adjust `habit_strength_scale`
   - If social influence wrong → adjust `social_influence_strength`
5. **Clamp parameters** to reasonable ranges
6. **Repeat** until convergence (25 iterations)

**Step 5: Generate Phase 4 Anchored Data**
```
• Re-run Phase 3 simulation with calibrated parameters
• Result: Phase 4 data that matches real data better
• Saved to: simulations/phase4_anchored.csv
```

## Key Points

### What Anchoring Does:
- ✅ **Calibrates simulation parameters** to match real data patterns
- ✅ **Uses ALL real data** (100% of available data)
- ✅ **Iteratively adjusts** parameters over 25 iterations
- ✅ **Minimizes error** between simulated and real metrics

### What Anchoring Does NOT Do:
- ❌ Does NOT mix real data into simulation
- ❌ Does NOT replace simulated data with real data
- ❌ Does NOT use only a subset of real data
- ❌ Phase 4 is still **simulated data**, just with **better parameters**

### The Anchoring Mechanism:

**Parameter-Based Calibration:**
- Real data → Target metrics (what we want to match)
- Simulated data → Simulated metrics (what we currently get)
- Difference → Parameter adjustments (how to fix it)
- Iterate → Convergence (get closer to target)

**Example:**
```
Real Data: Product Intent Mean = 0.6381
Phase 3:   Product Intent Mean = 0.6028 (error: 0.0353)
           → Increase agent_state_init_scale
Phase 4:   Product Intent Mean = 0.6094 (error: 0.0287)
           → Improvement: 18.8% error reduction
```
